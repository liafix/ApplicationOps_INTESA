This directory is an **engineering history archive** from the earlier pass-by-pass build workflow. Individual reports and gate outputs describe the state that existed at the time they were produced and may intentionally say that a later release gate was still blocked.

They are **not the current recruiter-demo release status**.

For the current GitHub/Vercel candidate release, use:

- root `README.md`
- `docs/PASS_16_PRACTICAL_FINAL_CANDIDATE_AUDIT.md`
- `.github/workflows/recruiter-demo.yml`
- `recruiter-demo/`
